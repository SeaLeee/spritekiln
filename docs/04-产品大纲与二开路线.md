# 04 · 产品大纲与二次开发路线

## 1. 定位
**SpriteKiln 像素窑**：给一人公司 / 独立游戏开发者的本地 AI 游戏素材工坊。
- 解决的问题：通用生图模型产出的图"不能直接进游戏"（尺寸、透明、网格、调色板、帧对齐、方向一致、引擎格式）。
- 差异化：本地优先（3090 上跑 Z-Image / MiniMax H3 / Pixal3D，零边际成本）+ 云端模型提升品质 + Agent 原生（Skill/CLI/MCP）+ Godot 直写。

## 3. 关键交互

1. **烧制**：选模块 → 选能力 → 填表（参数 schema 驱动）→「烧制」→ 窑炉出现任务卡（青釉→琥珀→余烬渐变进度、SSE 实时）→ 资产按血缘落在画布上。
2. **继续加工**：点资产 → 检查器 →「做动画 / 8 方向 / 万能编辑 / 变体 / 克隆 / 去背景 / 像素化 / 拆分 / 转 3D / 自循环」→ 表单自动带入源素材。
3. **Agent**：框选资产 → 在 Kiln Agent 输入需求 → 计划（可见步骤）→ 自动执行并回写进度。
4. **交付**：导出 ZIP 或「写入 Godot」。
